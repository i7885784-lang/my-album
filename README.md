# Мастерская семейного альбома

Статическая страница для выбора цветов, шрифтов и оформления будущего сайта.

## Запуск

Из `/workspace/my-album` выполните:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте страницу через просмотр приложения в вашей среде. Также можно открыть `index.html` непосредственно в браузере. Серверная часть и база данных для этого инструмента не нужны.

Пять готовых сочетаний, выбор своих цветов, четыре локальных шрифта с кириллицей, проверка контраста, узкий и широкий просмотр. Настройки сохраняются в localStorage; кнопка «Сохранить выбор» скачивает JSON с оформлением. Локальное сохранение зависит от разрешений браузера. Фотография заменена авторской SVG-иллюстрацией.

Шрифты: Lora, Golos Text, Onest, Literata из Fontsource, лицензия SIL Open Font License (см. assets/fonts).

## Запуск из ZIP

1. Распакуйте весь архив в отдельную папку.
2. Windows: дважды нажмите «Запустить.bat». Нужен Python 3 (при установке включите Add Python to PATH).
3. macOS/Linux: выполните `python3 launch.py` из папки проекта. В macOS также есть «Запустить.command»; система может запросить разрешение на запуск.
4. Браузер откроется автоматически. Окно сервера оставьте открытым; закрытие окна останавливает сайт.

Без Python можно открыть index.html двойным щелчком, но сохранение выбора при таком запуске зависит от браузера. Интернет после распаковки не нужен.

17 готовых палитр с фильтрами. Мастерская по умолчанию тёмная; её тему можно переключить отдельно от оформления альбома. Настройки темы сохраняются в браузере. Это инструмент выбора дизайна; база данных и публикация фотографий пока не реализованы.
