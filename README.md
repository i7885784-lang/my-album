# Рядом — семейный альбом

Два самостоятельных варианта оформления по выбранным референсам:

- **Лиловые воспоминания** — `album-purple.html`: фиолетовая обложка, фотографии-открытки, округлые формы и объёмные детали.
- **Зелёный архив** — `album-green.html`: шалфейная палитра, асимметрия и спокойные композиции.

Главная `index.html` позволяет выбрать вариант. Старая мастерская цветов сохранена в `workshop.html`, исследование референсов — в `research/REFERENCES.md`.

## Запуск в пару кликов

Распакуйте **весь** ZIP-архив. На Windows запустите **«Запустить.bat»**. Нужен Python 3; при установке включите Add Python to PATH. Браузер откроется автоматически. Окно сервера оставьте открытым, для остановки закройте его или нажмите Ctrl+C.

macOS/Linux: `python3 launch.py` в папке проекта. На macOS также есть «Запустить.command» (система может запросить разрешение на запуск).

Для разработки из `/workspace/my-album`:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Открыть HTML напрямую тоже можно, но для стабильного локального хранения фотографий используйте сервер. После распаковки интернет не нужен: шрифты, фотографии и файлы включены.

## Что работает

- Альбомы с фотографиями, фильтры, просмотр в диалоге с переключением стрелками и закрытием Escape.
- Избранное в localStorage.
- Загрузка своих JPG, PNG, WebP: до 10 фото за раз, до 10 МБ каждое. Проверяется возможность декодировать изображение.
- Фотографии сохраняются локально в IndexedDB, доступны после обновления страницы и в обоих вариантах на одном адресе сервера.
- Отдельный вечерний режим, запоминающий выбор, и мобильные версии.

**Это два работающих локальных прототипа для выбора дизайна.** Общего сервера, регистрации и общей базы данных пока нет. Локальные данные не синхронизируются между компьютерами и пропадут при очистке хранилища браузера. `launch.py` использует постоянный адрес 127.0.0.1:8765, чтобы локальные данные сохранялись между запусками. Браузерное хранилище привязано к адресу и порту: при использовании другого адреса, порта или браузера сохранённые фото не появятся. Если порт занят, остановите предыдущий экземпляр сервера.

Фотографии в примерах — демонстрационные пейзажи Ram Patra, не семейные снимки пользователя; источники и лицензия в `assets/photos/CREDITS.md` и `assets/photos/LICENSE.txt`. Макеты и код двух новых страниц созданы отдельно, без копирования исходного кода референсов.

Локальные шрифты Lora, Golos Text, Onest, Literata — Fontsource, SIL Open Font License. Для символов используется DejaVu Sans; тексты лицензий в `assets/fonts`.
