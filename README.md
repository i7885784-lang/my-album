# Семейные альбомы

Веб-приложение для личного семейного архива. React, TypeScript и Vite на клиенте, Express и SQLite на сервере. Фотографии и видео сохраняются на диске сервера. Интерфейс на русском языке.

## Запуск на Windows x86 и x64

Для 32-битной Windows 10 используйте установщик [Node.js 22 LTS x86](https://nodejs.org/dist/v22.23.5/node-v22.23.5-x86.msi). Для 64-битной Windows подойдёт Node.js 22 или 24 x64. Современные версии Node.js требуют Windows 10 или новее.

1. Установите [Node.js 22 LTS версии 22.13 или новее](https://nodejs.org/).
2. Распакуйте весь архив в доступную для записи папку.
3. Запустите `install.bat`. Для первой установки нужен интернет.
4. Запустите `start.bat`. Дождитесь открытия браузера.
5. Создайте аккаунт. Новый пользователь получает пустой личный архив.
6. Оставьте окно сервера открытым. Для остановки нажмите Ctrl+C.

При последующих запусках достаточно `start.bat`. Скрипт проверяет версию Node.js, установку и сборку, дожидается ответа сервера и открывает браузер. Если необходимые файлы ещё не установлены, запускает установку.

Адрес по умолчанию — `http://localhost:3000`. Не меняйте папку `storage`, если хотите сохранить архив. Перед обновлением сделайте резервную копию через настройки. Затем обновите исходники и повторите установку.

## Возможности

- Публичная главная и личная главная семейного архива, альбомы, фотографии, видео, избранное, люди, места, теги, корзина, воспоминания, настройки приложения и отдельные настройки профиля.
- Регистрация, вход, выход, хеширование паролей scrypt, серверные сессии в HttpOnly cookie, изменение профиля, email, пароля и аватара.
- Семейные пространства, одноразовые приглашения на 7 дней, роли владельца, участника и гостя, отзыв доступа.
- Приватные альбомы, доступ семье или выбранным участникам. Проверка доступа выполняется на сервере, включая оригиналы, миниатюры и видеопревью.
- Загрузка JPG, PNG, WebP, GIF, MP4 и WebM. До 20 файлов в очереди, по умолчанию до 200 МБ на файл. Файлы отправляются автоматически после выбора. Реальный прогресс передачи отделён от обработки на сервере. В архив попадают подтверждённые сервером файлы, миниатюры предварительно загружаются в браузере. Неудачные загрузки можно повторить. Перед выбором файлов укажите семью, альбом, место и теги. Альбом и место фиксируются на время очереди, чтобы сразу применить нужный доступ. Участник может загружать фотографии в доступный семейный альбом; гость — только просматривать.
- Оригиналы хранятся без изменения. Нативный FFmpeg создаёт миниатюры фотографий, постеры и MP4-превью видео. FFmpeg устанавливается пакетом для текущей ОС.
- Создание, изменение и удаление альбомов, тегов, людей и мест. Обложки из загруженных фотографий, даты событий и настройки доступа альбомов.
- Ручная привязка фотографий к людям, местам, тегам и альбомам. Массовые операции, копирование связей в другие коллекции и удаление из коллекции.
- Поиск по названиям и связям, переход к найденным коллекциям, фильтры по году, сезону, человеку, месту и типу, сортировка и постраничное отображение по 120 файлов.
- Просмотрщик с клавиатурной навигацией, масштабом, поворотом, полноэкранным режимом, скачиванием оригинала, избранным и комментариями.
- Интерактивная Leaflet-карта с OpenStreetMap, маркерами и кластерами. Места выбираются вручную при загрузке фото и создании альбома. Новое название автоматически появляется во вкладке «Места». Фото без собственного места наследуют место альбома. Точку на карте можно необязательно указать вручную; карта отображается, когда есть такие точки. GPS из фотографий не считывается.
- Корзина с восстановлением связей. Окончательное удаление требует подтверждения. Срок хранения — 30 дней, проверка истечения при запуске и каждые 24 часа.
- Светлая и тёмная темы для страниц, раскрытых списков, календаря, подтверждений и всех окон. Выбор темы, анимаций, приватности новых альбомов и уведомлений сохраняется в SQLite. Системное уменьшение движения учитывается автоматически.
- Кнопка профиля справа сверху открывает личные данные, семейные пространства, приглашения и обложку главной. Обложку можно выбрать из архива или загрузить, положение кадра регулируется ползунком. На остальных страницах используется заголовок без фонового изображения.
- Уведомления о комментариях владельцу и новых семейных загрузках участникам с доступом. Браузерные уведомления включаются только по нажатию «Разрешить уведомления» и после сохранения настройки. Требуются HTTPS или localhost и поддержка браузера. Пока сайт открыт в другой вкладке, новые события проверяются примерно раз в 15 секунд; фоновые таймеры могут замедляться браузером. При полностью закрытом сайте доставка не работает, Web Push не настроен.
- Воспоминания содержат подборки «В этот день», «В этом месяце», «Любимые моменты», историю по годам и события месяца из дат альбомов. Дата снимка берётся из EXIF, при её отсутствии используется дата загрузки.
- Владелец семьи может добавить участнику семейную пометку, включить режим «Только просмотр» и скрыть отдельные альбомы. Запрет действует для фотографий из этих альбомов во всех разделах и через API, включая прямые ссылки и экспорт. Открытая вкладка проверяет изменение доступа примерно раз в 15 секунд и при возвращении в неё. Ранее скачанные участником файлы отозвать невозможно.
- Хранилище показывает размер собственных оригиналов, миниатюр, превью и корзины, а также реальное свободное место на общем диске сервера. Фиктивная квота не используется.
- ZIP-экспорт собственных оригиналов, коллекций, связей и избранного. Импорт копии создаёт новые объекты и сохраняет текущие данные.

До входа открывается публичная главная с регистрацией и входом. Внутренние разделы доступны после авторизации. После регистрации пользователь попадает в свой семейный архив.

## Разработка и Linux/macOS

```sh
npm ci
npm run dev
```

Сервер разработки обслуживает API и Vite на одном порту. Проверка готовности выполняется запросом `GET /api/health`.

```sh
npm run build
npm test
NODE_ENV=production npm start
```

Для проверки интерфейса нужен установленный Python Playwright и Chromium. Тест использует отдельный сервер с пустым тестовым хранилищем.

```sh
PORT=3200 STORAGE_DIR=/tmp/album-ui-test NODE_ENV=production npm start
# В другом терминале из корня проекта
python3 tests/browser_smoke.py
python3 tests/interface_review.py
python3 tests/responsive_theme_review.py
TEST_STORAGE=/tmp/album-ui-test python3 tests/family_features_review.py
python3 tests/live_access_review.py
```

Путь к Chromium и каталог скриншотов в браузерном тесте соответствуют облачной Linux-среде. Для другой машины их необходимо адаптировать. Подробная проверка interface_review.py проходит раскрытые списки, календарь, подтверждения, загрузку, приглашения и роли, комментарии, полноэкранный просмотр, карту и обложку профиля. Скриншоты сохраняются в SCREENSHOT_DIR. Проверка family_features_review.py проверяет ручные места, семейные ограничения, доставку уведомлений, запрос разрешения и семь мобильных размеров; TEST_STORAGE должен указывать на отдельное тестовое хранилище сервера, поскольку тест создаёт историческую дату снимка в тестовой базе. Проверка responsive_theme_review.py дополнительно проходит все вкладки и основные окна в обеих темах на семи сенсорных размерах экрана, проверяет длинные названия, вход и регистрацию, поворот телефона, планшет и настольные размеры.

Архив выпуска создаётся командой `node scripts/package.mjs`. В него входят исходники, собранный клиент, статические ресурсы и BAT-файлы. Хранилище, node_modules, Git-метаданные и секреты исключаются.

## Конфигурация

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| PORT | 3000 | Порт сервера |
| HOST | 127.0.0.1 | Адрес прослушивания |
| STORAGE_DIR | storage в корне | База, оригиналы, миниатюры и видеопревью |
| MAX_UPLOAD_MB | 200 | Максимальный размер одного файла |
| NODE_ENV | development | production обслуживает собранный клиент |
| COOKIE_SECURE | false | true для HTTPS |

Для доступа из домашней сети задайте `HOST=0.0.0.0` и откройте порт в брандмауэре. Все устройства должны обращаться к одной работающей машине. Публикация в интернет требует собственного HTTPS-развёртывания.

Не копируйте работающую SQLite-базу отдельно от WAL-файлов. Используйте экспорт в приложении для переноса собственного медиаконтента. Для полного переноса аккаунтов и семейных пространств остановите сервер и скопируйте всю папку `storage`.

## Проверки и ограничения

Сборка TypeScript/Vite и интеграционный API-тест проверяют регистрацию, cookie, коллекции, загрузку, миниатюры, запрет чужого доступа, семейное приглашение, приватность, комментарии, настройки, перезапуск, видео, резервную копию и корзину.

Проверка Chromium охватывает создание аккаунта и альбома, мультизагрузку, просмотрщик, избранное, разметку, восстановление и сохранение темы, загрузку и воспроизведение MP4/WebM, редактирование профиля, email, пароля и аватара. Проверяются ширины телефонов 320, 360, 375, 390, 412, 430 и 480 px, поворот экрана 568×320, 740×360, 844×390 и 932×430, планшет 768×1024 и настольные размеры до 1920×1080. Это эмуляция Chromium, а не проверка на физических телефонах.

Выбранная тема сразу применяется ко всему интерфейсу, включая публичную главную, вход и регистрацию. В настройках она сохраняется автоматически в аккаунте и на устройстве. Переходы, обновление страницы и выход из аккаунта не сбрасывают выбор. На телефоне обложка главной показана отдельным блоком над текстом, а длинные имена в карточках, списках и поиске сокращаются многоточием.

- Windows BAT-файлы используют ASCII и CRLF, включая GitHub ZIP. Установка пакетов Windows x86 проверена с выбором платформы win32/ia32. Обработка фотографий выполняется нативным FFmpeg, включая пакет win32-ia32. Проверены JPG, PNG, WebP, GIF, ориентация EXIF и восстановление миниатюр из резервной копии. Зависимости Sharp и Sharp WASM удалены из проекта. Сборка и API-тесты также прошли на Node.js 22. Запуск на Windows x86 в этой Linux-среде не проверялся.
- Автоматическое распознавание лиц недоступно. Люди размечаются вручную.
- Фоновая автозагрузка с устройств и почтовая отправка приглашений отсутствуют. Приглашения передаются кодом.
- HEIC и MOV не принимаются. Видео обрабатывается при загрузке, поэтому после передачи файла нужно дождаться сохранения.
- Картографический фон требует подключения к tile.openstreetmap.org. При сетевом отказе интерфейс сообщает об этом.
- Стандартный семейный баннер отличается от исходных изображений референсов. Компоновка, цвета и основные компоненты воспроизведены по предоставленным макетам.
- Архив через интерфейс ограничен текущим лимитом загрузки при импорте и 2 ГБ распакованных данных. Полное хранилище большего размера переносите при остановленном сервере.
- Корзина очищается по сроку без дополнительного подтверждения. Подтверждение требуется при ручном окончательном удалении.
- Постраничное отображение и поиск проверены на архиве из 10 000 синтетических JPEG 64×64. Скорость массового создания миниатюр после перехода на нативный FFmpeg повторно не измерялась. Скорость обработки полноразмерных фото и длинных видео зависит от оборудования.
